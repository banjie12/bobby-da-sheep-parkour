# Bobby da Sheep Parkour
## Planned final game
### Objective
The objective of the game is to control a ginger-wooled sheep named Bobby da Sheep (or Bobby for short) and parkour up to the sheep pen.
### Controls
Left: A or left arrow  
Right: D or right arrow  
Jump: W, up arrow or space bar
